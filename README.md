# Novique Website

Static marketing website for Novique built as a single-page [index.html](index.html) using:

- Tailwind CSS (CDN)
- Lucide icons
- Vanilla JavaScript interactions

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- The full landing page markup, styles, and scripts live in [index.html](index.html).
- This project is configured as a website (not a React application).
